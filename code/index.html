Como jogar

  1. Clique em Iniciar para começar a partida.
  2. Observe a sequência de cores que o jogo acende.
  3. Repita a sequência clicando nos botões na mesma ordem.
  4. A cada acerto, a sequência ganha uma cor a mais.
  5. Cada erro custa uma vida; ao perder as 3 vidas, a partida termina.
  6. Vence quem completar a rodada 10 sem perder todas as vidas.
